# Methodology

## 1. Data Preparation

The cleaned e-commerce dataset from decodelabs project 1:
Data cleaning and preparation was used as the foundation of the explanatory data analysis conducted in pject 2.

Since the data had already undergone data cleaning and quality checks in project 1,
the focus in this stage was on reviewing the cleaned dataset,
confirming that the relevant fields were suitable for analysis, and preparing the data for
trend analysis
outlier analysis
explanatory data analysis(EDA)
and visualization using Microsoft Excel.

## 2. Descriptive Statistics

Descriptive statistics were calculated to understand the central
tendency and range of key numerical variables.

Metrics included:

- Mean
- Median
- Minimum
- Maximum

## 3. Trend Analysis

PivotTables were used to analyze:

- Monthly order volume
- Monthly total sales
- Product sales performance
- Order status distribution
- Payment method distribution

## 4. Outlier Analysis

The Interquartile Range (IQR) method was used to identify potential
outliers in TotalPrice.

A Box & Whisker chart was also used to visually examine the
distribution and potential extreme values.

## 5. Exploratory Data Analysis Visualizations

The analysis was presented through:

- Line charts
- Bar charts
- Column charts
- Distribution charts
- Box & Whisker charts

## 6. Key Insights

The findings were interpreted to identify meaningful trends,
patterns, sales behavior, and unusual observations within the
dataset.
