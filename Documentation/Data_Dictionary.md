# Data Dictionary

| Column | Description |
|---|---|
| OrderID | Unique identifier for each order |
| Date | Date associated with the order |
| MonthYear | Month and year derived from the order date |
| Month | Month derived from the order date for trend analysis |
| MonthNum | Numeric representation of the month (1-12) |
| CustomerID | Unique identifier for the customer who placed the order |
| Product | Product purchased |
| Quantity | Number of units purchased |
| UnitPrice | Price per unit |
| ShippingAddress | Delivery address for the order |
| PaymentMethod | Payment method used for the order |
| OrderStatus | Current status of the order |
| TrackingNumber | Shipment tracking ID for the order |
| ItemsInCart | Number of items associated with the order/cart |
| CouponCode | Discount code applied to the order, if any |
| ReferralSource | Channel through which the customer found the store |
| TotalPrice | Total value of the order |
